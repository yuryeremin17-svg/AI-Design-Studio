# Social Psychology in Brand Design — Практический справочник

> Каждый принцип → конкретное дизайн-решение.
> Используется на шагах 1.1, 3.1, 3.2, 4.3 алгоритма.

---

## 1. HALO EFFECT (Эффект ореола)

**Механизм:** Впечатление от одного элемента переносится на все остальные.

**Иерархия инвестиций (по ROI):**
1. **Типографика** — определяет 60-70% восприятия. Плохой шрифт убивает хороший логотип.
2. **Логотип** — первый контакт, якорь памяти.
3. **Цветовая палитра** — запоминается на 80% лучше формы.
4. **Spacing/Layout** — бессознательно определяет "дорого vs дёшево".
5. **Фотостиль** — сильный halo, но зависит от бюджета.

**Антипаттерн:** Дорогой логотип + бесплатные шрифты + тесная вёрстка = halo в минус.

**Применение:** При ограниченном бюджете (Старт) — инвестировать в шрифтовую пару + spacing.

---

## 2. MERE EXPOSURE (Эффект знакомства)

**Механизм:** 7-15 контактов с одинаковым визуалом → предпочтение. CSS-переменные = гарантия consistency.

**Что повторять (высокая частотность):**
- Цветовая пара (primary + accent) — в КАЖДОМ touchpoint
- Пропорции логотипа — повторять в карточках, рамках
- Spacing grid (8px) — везде одинаковый
- Один декоративный элемент (рамка, линия, паттерн)

**Что варьировать:** Layouts, вторичные цвета, масштаб.

**Применение:** Минимум 7 носителей с единой системой (визитка, бланк, соцсети, email, презентация, упаковка, сайт).

---

## 3. SOCIAL PROOF (Социальное доказательство)

**Визуальные сигналы качества:**

| Сигнал | Как работает | Реализация |
|--------|-------------|------------|
| Whitespace | Много пустого = уверенность | Margins 15-20% от ширины |
| Сдержанность палитры | 2-3 цвета = дисциплина | Один акцент + нейтралы |
| Весомая типографика | Serif с контрастом = "мы здесь давно" | Cormorant, Playfair для заголовков |
| Двойная рамка / тонкие линии | Отсылка к сертификатам = авторитет | ::after, 0.5pt, 3pt зазор |
| Монохромная версия | "Бренд работает без цвета" | Проектировать сначала в ч/б |

---

## 4. IN-GROUP SIGNALING (Сигналы принадлежности)

### Визуальные коды по сегментам:

**LUXURY / OLD MONEY:**
- Serif с высоким контрастом, симметрия, центральная ось
- Navy, cream, gold, burgundy
- Тонкие линии, двойные рамки, минимум декора
- Бренды: The Row, Brunello Cucinelli, Loro Piana

**VINTAGE / НОСТАЛЬГИЯ:**
- Rounded serif, dusty/muted цвета, мягкие углы
- Иллюстрации, штриховка, текстуры бумаги
- Бренды: Anthropologie, Le Labo, Byredo

**MODERN PREMIUM:**
- Geometric sans + один serif акцент, чёрный/белый + яркий акцент
- Асимметрия, контрастные размеры
- Бренды: COS, Acne Studios, Everlane

**WARM FRIENDLY PREMIUM:**
- Humanist serif + rounded sans, тёплые приглушённые цвета
- Мягкие пропорции, деликатные рамки
- Бренды: Kaori, Anthropologie, Toast (UK)

## 5. МОДЕЛЬ НОРМАНА (Три уровня восприятия)

### Visceral (инстинктивный) — первые 50мс
Что мозг решает: "красиво/уродливо", "для меня/не для меня"

| Элемент | Решение |
|---------|---------|
| Тёплый цвет | → безопасный |
| Высокий контраст | → энергия |
| Скруглённые углы | → дружелюбный |
| Тонкий шрифт | → элегантный |
| Золотое сечение | → "правильно" (бессознательно) |

**Применение:** Обложка, визитка, лого — проектировать для visceral. Никаких компромиссов на первом экране.

### Behavioral (поведенческий) — удобно ли
- Контраст текста: мин. 4.5:1 body, 3:1 заголовки
- Размер: 16px мин. экран, 10pt мин. печать
- Иерархия: макс. 3 уровня на одном экране
- Навигация: кликабельное содержание

### Reflective (рефлексивный) — что это говорит обо мне
- "Хочу ли я ассоциироваться с этим брендом?"
- Страница "О бренде", Tone of Voice, фотостиль — для reflective
- Клиент должен хотеть показать бренд друзьям

## 6. НОСТАЛЬГИЯ ЧЕРЕЗ ДИЗАЙН (без устаревания)

**Правило:** "Ностальгический" ≠ "старомодный". Ностальгия = тёплое чувство. Старомодный = буквальное копирование прошлого.

**Техники:**
1. **Типографика:** Cormorant, Playfair, Lora — отсылка к антикве, но modern metrics. НЕ Old English.
2. **Цвет:** Снизить saturation на 15-25%, добавить тёплый подтон. НЕ sepia фильтр.
3. **Текстуры:** Лёгкая зернистость (noise 2-3%), тонкие линии. НЕ "потёртости".
4. **Композиция:** Центральная симметрия, овалы, арки.
5. **Иллюстрация:** Ботаническая, line art. НЕ "состаренное фото".

---

## 7. "СЛАДКАЯ ТОЧКА" — Премиум, но доступный

| Элемент | Холодный люкс | Сладкая точка | Mass market |
|---------|--------------|---------------|-------------|
| Цвет | Чёрный + золото | Тёмный тёплый + шампань | Яркие + белый |
| Шрифт | Didot (высокий контраст) | Cormorant (контраст, но теплее) | Open Sans |
| Spacing | Огромные поля | Щедрые, не расточительные | Плотно |
| Декор | Нет | Деликатный (тонкая рамка) | Много |
| Голос | "Мы не объясняем" | "Рады поделиться красотой" | "Купи сейчас!" |
| Фото | Один объект, пусто | Атмосферные, тёплые | Каталожные |

**Принципы:**
1. Тёплый тон вместо холодного
2. Один элемент роскоши (якорь), не весь дизайн
3. Голос = приглашение, не исключение
4. Детали видны при внимательном взгляде
5. Натуральные текстуры (лён, крафт, дерево)

## СВОДНЫЙ ЧЕКЛИСТ (перед началом дизайна)

```
□ Halo: шрифтовая пара — лучшая для этого архетипа?
□ Mere exposure: CSS-переменные обеспечивают 100% consistency?
□ Social proof: whitespace достаточный? палитра сдержанная (≤3 активных цвета)?
□ In-group: визуальные коды совпадают с сегментом клиента?
□ Visceral: первый экран вызывает мгновенную реакцию "красиво / для меня"?
□ Behavioral: всё читаемо? навигация очевидна? контраст ≥ 4.5:1?
□ Reflective: клиент захочет показать это друзьям?
□ Ностальгия (если нужно): приглушённые тона, тёплый подтон, без буквализма?
□ Sweet spot (если luxury≤3): тёплый, не холодный? доступный, не дешёвый?
```
