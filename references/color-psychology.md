# Color Psychology — Справочник выбора цвета

> Источники: Ignyte 5-Criteria Model, HelpScout, ResearchGate 2025
> 85% покупателей называют цвет основной причиной выбора бренда
> Цвет увеличивает узнаваемость бренда до 80%

## 5-Criteria Color Decision Model (Ignyte)

### Критерий 1: Отрасль

| Отрасль | Традиционные цвета | Альтернативы |
|---------|--------------------|-----------------------|
| Финансы / Банки | Синий, тёмно-зелёный | Navy + золотой |
| Технологии | Синий, фиолетовый | Чёрный + яркий акцент |
| Здоровье / Wellness | Зелёный, бирюзовый | Тёплый белый + sage |
| Мода / Beauty | Чёрный, белый, розовый | Бордовый, gold |
| Еда / Ресторан | Красный, оранжевый, зелёный | Терракота, olive |
| Luxury | Чёрный, золотой, navy | Изумрудный, cream |
| Винтаж / Антиквариат | Бордо, крем, золотой | Dusty tones, plum, olive |
| Дети / Образование | Яркие, мультицвет | Пастельные |
| Недвижимость | Синий, зелёный | Тёмно-серый + медный |

### Критерий 3: Аудитория

| Параметр аудитории | Рекомендация |
|--------------------|-------------|
| Женщины 25-45 | Мягкие тёплые тона, rose, dusty colors |
| Мужчины 30-50 | Тёмные, насыщенные, контрастные |
| Молодёжь 18-25 | Яркие, неоновые, градиенты |
| Премиум-аудитория | Приглушённые, глубокие, с металликом |
| Массовый рынок | Чистые основные цвета |
| Eco/Wellness | Природные, земляные, мягкие |

### Критерий 4: Конкуренты
- Нанести цвета конкурентов на цветовой круг
- Найти незанятый сектор
- Исключить avoid_colors из брифа

### Критерий 5: Структура палитры (5 цветов)
```
1. Primary — главное сообщение бренда
2. Secondary — поддержка, контраст
3. Accent — CTA, выделения
4. Light — фоны, пространство
5. Dark — текст, контрастные секции
```

|------|-----------|-----------|-------------|----------------|

| Оранжевый | Тепло, дружелюбие | Дешевизна | Tech, friendly | Luxury, финансы |
| Жёлтый | Оптимизм, креатив | Тревога, дешевизна | Детские, creative | Серьёзные B2B |
| Зелёный | Рост, здоровье | Зависть, застой | Eco, wellness | Luxury (кроме emerald) |
| Бирюзовый | Ясность | Холодность | Образование, tech | Тёплые бренды |
| Синий | Доверие, стабильность | Холодность, скука | Финансы, tech | Еда |
| Фиолетовый | Мудрость, роскошь | Мрачность | Luxury, creative | Массовый рынок |

## Культурные нюансы

### СНГ (Россия, Украина, Казахстан)
- **Чёрный фон** = "дорого" (наследие 90-х), но женщины 25-45 устали — тренд на тёплые тона
- **Фиолетовый** — позитивнее чем на Западе (загадочность, не траур)
- **Синий** — "безопасный", но для премиум/винтаж слишком корпоративный
- **Золотой** — ТОЛЬКО muted/champagne (#C5A882). Яркое золото (#FFD700) = "турецкий базар"
- **Пыльные тона** — тренд 2024-2026: dusty rose, sage, terracotta

### ОАЭ / Арабский мир
- **Зелёный** — священный цвет ислама, использовать с уважением
- **Золотой** — очень позитивный, символ благополучия
- **Белый** — чистота, часто основной фон
- **Чёрный** — элегантность (не траур как в Европе)
- **Красный** — осторожно: может ассоциироваться с опасностью

### Международный
- Синий — самый универсально-позитивный цвет
- Красный — внимание, но культурно неоднозначен
- Белый — чистота на Западе, траур в Азии

## Проверка контраста

**Обязательно перед утверждением палитры:**
- Dark на Light фоне: contrast ratio ≥ 4.5:1 (WCAG AA body text)
- Primary на Light фоне: ≥ 3:1 (WCAG AA large text/headings)
- Light текст на Dark фоне: ≥ 4.5:1

**Инструмент:** WebAIM Contrast Checker или ручной расчёт.
**Антипаттерн:** тёмный текст (#3D2B35) на тёмном фоне (#5C3A4E) — НЕЧИТАЕМО.
