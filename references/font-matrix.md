## Психология категорий шрифтов

| Категория | Черты характера | Когда использовать |
|-----------|----------------|-------------------|
| **Serif** (Garamond, EB Garamond) | Классический, надёжный, авторитетный | Heritage, luxury, финансы, юриспруденция |
| **Sans-serif** (Inter, DM Sans) | Современный, чистый, доступный | Tech, стартапы, digital |
| **Humanist sans** (Lato, Source Sans Pro) | Тёплый, дружелюбный, человечный | Caregiver, wellness, образование |
| **Geometric sans** (Montserrat, Poppins) | Структурный, современный | Design, corporate, tech |
| **Script** (курсивные) | Элегантный, личный | Luxury акценты (только заголовки!) |
| **Display** (Bebas Neue, Anton) | Экспрессивный, мощный | Спорт, entertainment, headlines only |
| **Slab serif** (Roboto Slab) | Уверенный, заземлённый | Industrial, craft |
| **Monospace** (IBM Plex Mono) | Технический, точный | Tech, developer tools |

## Правила выбора

1. **Halo effect:** шрифтовая пара = 60-70% восприятия бренда. Инвестировать первой.
2. **Контраст пары:** заголовочный и текстовый ДОЛЖНЫ отличаться по категории (serif + sans, display + humanist).
3. **Кириллица:** ВСЕГДА проверять до выбора. Если нет кириллицы — искать замену.
4. **Вес:** Light = деликатный, элегантный. Bold = уверенный, сильный. Выбор веса = тонкая настройка архетипа.
5. **Размеры для печати:** заголовок мин. 12pt, текст мин. 10pt, подписи мин. 7pt.
6. **Размеры для экрана:** body мин. 16px, заголовок — по шкале (Perfect Fourth 1.333 или Major Third 1.25).
