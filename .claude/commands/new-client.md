Новый клиент. Входные данные: $ARGUMENTS

Шаг 1 — Структура:
1. Создай папку output/[имя-клиента]/
2. Создай папку assets/logos/[имя-клиента]/

Шаг 2 — Бриф:
- Если есть brief-response.json в output/[имя-клиента]/ — использовать его
- Если нет — максимум 2 вопроса: стиль? пакет (Старт/Бизнес/Премиум)?

Шаг 3 — BRAND ALGORITHM (ОБЯЗАТЕЛЬНО перед дизайном):
- Выполни BRAND-ALGORITHM.md Фазы 0-2 полностью
- Артефакты: brief-analysis.md + brand-strategy.md в output/[имя-клиента]/
- Без завершённых Gate 1 и Gate 2 — к дизайну НЕ приступать

Шаг 4 — Дизайн-решения (из brand-strategy.md, НЕ из головы):
- Шрифтовая пара → из стратегии (references/font-matrix.md)
- Палитра → из стратегии (5 цветов по 5 критериям)
- Создай логотип (SVG: основной + light для тёмного фона + icon для аватарки)

Шаг 5 — Покажи решения клиенту (Фаза 3 алгоритма):
- Палитра + шрифты + логотип — на одном экране
- Дождись одобрения или правок

Шаг 6 — Производство (Фаза 4 алгоритма):
- Создай брендбук (HTML, дизайн-система v3: CSS-переменные, 8px grid, reveal-анимации, progress bar, copy HEX)
- Визитка встроена в брендбук (секция 09)
- Проверь через Playwright

Шаг 7 — Доставка:
- Запусти: node scripts/deliver-v2.js [имя-клиента]
- ZIP готов в delivery/[имя-клиента]/

Шаг 8 — Запиши клиента в MEMORY.md
