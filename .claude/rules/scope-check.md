Правило "Что за рамкой?" — обязательно перед любым изменением.

Триггеры (когда срабатывает):
- Edit с replace_all
- Удаление или переименование файла
- Изменение, затрагивающее >1 файла
- Любой рефакторинг (переименование функции, переменной, класса)

Перед действием — обязательный блок:

1. **За рамкой:** что ещё затронуто? (grep/Glob — не по памяти)
2. **Путь A vs Путь B:** минимум 2 варианта, выбрать где меньше действий
3. **Доказательство:** grep/Read результат, подтверждающий безопасность

Если ответ "ничего не затронуто" — значит не проверил. Перепроверить.

Запрещено:
- replace_all без предварительного grep по old_string
- Удалять файл без grep по его имени (кто на него ссылается?)
- Переименовывать без grep по старому имени
