2. Добавляй `--sref <URL_первой_картинки>` ко ВСЕМ остальным промптам
3. Это закрепит стиль серии (палитра, освещение, текстура)
4. Генерируй партиями по 4-5 за раз
5. Сохраняй в `ai-visuals/` под именами из этого файла
6. Скажи когда готово (или по партиям — я буду вставлять по мере поступления)

## ⚙️ Технические заметки

- `--ar 3:2` — горизонтальная картинка, впишется в правую половину слайда (640×426 px в слайде)
- `--style raw` — без «MJ-украшательств», ближе к фотореализму
- `--v 6.1` — последняя стабильная модель
- `--sref ... --sw 200` — сильное закрепление style reference (max=1000)
- Если MJ выдаёт нежелательное (текст на картинке, ненужные объекты) — `--no text, logo, watermark, words`
